# Galaxy Morphology Classification

This project explores a hybrid deep learning approach combining CNNs and Vision Transformers (ViT) for galaxy classification.

## Key Idea
A "gatekeeping" system where:
- CNN handles easy cases
- ViT handles uncertain cases

## Results
- Hybrid matches ViT accuracy (~75%)
- More efficient than using ViT alone
